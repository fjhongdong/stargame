# 星球大爆炸 · Planet Boom

网页版多人星球竞技游戏。包含完整中文大厅、房间码、实时联机、AI 练习、成长强化和手机触控。

在线试玩：https://planet-boom-stargame.onrender.com 。Render 免费服务闲置后再次访问可能需要等待唤醒。

## 启动

需要 Node.js 20 或更新版本。

要在本机外部浏览器里玩，Windows 双击 `start-game.cmd`，macOS 运行 `start-game.command`。也可在任意系统执行 `npm ci` 后运行 `npm run play`。启动程序会自动选择从 3001 开始的空闲端口，并打开本机默认浏览器。命令必须在你自己的电脑上执行；在云端执行只能启动云端服务。

```sh
npm ci
npm start
```

打开 `http://localhost:3001`。本机开两个浏览器标签页即可创建和加入同一个房间。局域网内的朋友可以打开服务器机器的局域网 IP，例如 `http://192.168.1.10:3001`，再输入房间码。

如果端口已被其他服务使用，可指定另一个端口启动，例如 `PORT=3002 npm start`（Linux / macOS）。PowerShell 使用 `$env:PORT=3002; npm start`。只需更改服务端端口，网页与 WebSocket 会自动使用相同地址。

```sh
npm test
```

测试覆盖真实 WebSocket 双人房间、准备和房主权限、同步移动、重连、引力吸收、碰撞碎裂、质量守恒、碎片抢回、分裂合并和随机强化。

## 核心玩法

- **大地图探索**：星域大小为 12000 × 8000，镜头跟随自己的星球，并通过小地图定位。地图保有 6000 个自然碎片，开局附近有可供成长的碎片，远处仍有完整探索空间。
- **引力吸收**：引力只在每颗星球的有效范围内牵引星屑与自由碎片，范围外没有引力加速度。质量越大，引力范围越广、吸力越强，移动速度越慢。多个星球争抢时，根据质量与距离决定主要吸引者。引力不会自动移动玩家控制的星球。
- **实体碰撞与碎裂**：星球在实体边缘接触时碰撞、弹开，不会相互穿透。保护期结束后，只要单颗星球质量更大，就会撞裂较小星球；等大星球只发生实体碰撞。小星球按质量平均裂成 3～4 份，其中一份保留为原玩家控制的核心，其余成为等质量的自由碎片。大星球也同时剥落自身质量的 5%，成为自由碎片。碰撞按双方质量交换动量，碎片继承原运动速度，剥落会带来轻微反冲；接触点的闪光和碎屑随撞击速度增强。双方总质量保持不变，核心短暂受保护。
- **重新吸收**：自由碎片可被任何星球吸收，包括原玩家。碎片短暂散开后可争抢；原主人约 0.9 秒后可以重新吸收。碎裂与回收保持质量，不会靠重复回收凭空刷分。
- **核心与主动分裂**：玩家控制的存活核心不会被直接吞噬；可吸收的是星屑与自由碎片。主动分裂用于追击，单球质量达到 48 可以分裂，最多 8 个受控分身，约 12 秒后靠拢合并。主动分身与碰撞产生的自由碎片是两种状态。
- **随机三选一**：总质量首次达到 60、100、160、240、360、520 时，随机提供三个不同属性。选择后立即生效，包含移动、成长、引力、护盾、引力波射程、能量恢复、技能消耗和冷却。多人对局不会暂停。降低质量再增长不会重复刷成长奖励。
- **前向引力波**：按 E 从星球前缘沿实际前进方向发出一道弧形引力波，向前传播并攻击途中的对手；静止时沿最后朝向发射。每道波对同一对手只造成一次伤害，基础消耗 30 能量。生命归零后重新出生，本局已选择的强化保留。
- **胜负**：每局 3 分钟，按最终总质量排名，同质量比较分数和击败数。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 按住 WASD / 方向键推进；松手后惯性滑行并逐渐减速，反向按键制动、转向；鼠标不控制星球 |
| 主动分裂 | 空格 |
| 吐出星屑 / 喂给好友 | Q |
| 前向引力波 | E |
| 加速 | Shift |
| 选择随机强化 | 点击卡片或 1 / 2 / 3 |
| 全屏显示 | 右上角全屏按钮；Esc 退出浏览器全屏 |

游戏画面铺满浏览器窗口。进入时会尝试开启系统全屏，也可用右上角按钮切换；不支持系统全屏的浏览器仍可使用完整窗口。移动带有惯性：按键或摇杆提供推进，松手后继续滑行并受阻力减速，反向操作可以制动后转向。手机使用左侧摇杆推进，右侧提供操作按钮；横屏更方便。

## 联机与部署

`npm start` 同时提供静态网页与 `/ws` WebSocket 服务。快速匹配会加入开放的等待房间；好友房间通过六位码加入。在线模式需要至少两名玩家，大家准备后由房主开始。自由练习自动加入四名 AI，无需等待。

生产部署到支持长连接的 Node.js 主机或容器。设置 `PORT` 即可更改端口，默认监听 `0.0.0.0:3001`。反向代理必须转发 `/ws` 的 WebSocket Upgrade；HTTPS 页面会自动使用 WSS。服务健康检查为 `/api/health`。

提供的 Dockerfile 可直接构建与运行：

```sh
docker build -t planet-boom .
docker run --rm -p 3001:3001 planet-boom
```

当前为单进程实时游戏服务器：房间在内存中，重启会清空，断线保留约 30 秒重连机会。多个实例需要房间路由或共享实时状态。线上服务位于 Render 新加坡区域，使用免费方案。

## 大地图性能

服务器用空间索引查询附近的引力碎片与碰撞对象，按玩家视野发送场景。客户端使用跟随镜头、移动预测与平滑校正，在收到服务端输入确认后修正位置；所有质量、碎裂、吸收与强化结果仍由服务器计算。

画面只绘制视野内对象，并复用星球和碎片的图像缓存。FPS 与网络往返时间可用于区分绘制卡顿和网络延迟；本机性能测试结果不能代表所有设备与公网连接的体验。

## 文件

- `server.mjs`：HTTP、WebSocket、房间与会话生命周期。
- `shared/engine.js`：服务器权威游戏模拟、碰撞、引力与强化。
- `public/`：无需构建的大厅与 Canvas 游戏界面。
- `test/`：游戏规则和真实双客户端网络测试。

所有星球、星空、碎片和音效均由程序生成，无需外部素材或第三方服务账号。
